# Programs (과학교육 프로그램)

서울대학교 과학교육과 교수님별 과학교육 프로그램의 기획·운영 자료 저장소입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `informal-students/` | 비형식 과학교육 – 학생 대상 (과학영재원, 주말 프로그램, 캠프 등) |
| `informal-public/` | 비형식 과학교육 – 시민 대상 (시민특강, 활동 등) |
| `formal/` | 형식 교육 (학교 교육과정 연계 프로그램) |
| `teacher-education/` | 교사교육 (예비교사·현직교사 연수 등) |

## 파일명 규칙

`연도_교수님_프로그램명_자료종류` (예: `2026_홍길동_시민특강_기획안.pdf`)

## 자료 제출

자료 등록은 담당자(BK21 인포스피어 과학교육연구단 박소연 연구원, soyeonpark@snu.ac.kr)에게 파일과 기본 정보(학과, 교수님, 분류, 연도, 공개 여부)를 보내 주세요.
